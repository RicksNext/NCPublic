FAQs

Which platforms are supported?

We currently support YouTube, Twitter / X, TikTok, Threads, BlueSky, Twitch, Instagram (beta), Rumble, Discord, Kick, Triller, and special charity trackers like TeamTrees and TeamSeas.

How fast are the updates?

Live counters refresh in real time where available. Some platforms apply rate limits, but we keep the experience as close to live as possible.

Can I compare multiple creators?

Yes, you can! Use the Compare tool to run head-to-head counters and monitor the live gap between creators or videos.
